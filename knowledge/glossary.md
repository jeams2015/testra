# Knowledge Base — Nimbo Store · Glosario

> Terminología del dominio. La lee el **Analyst** para interpretar bien los tickets.

| Término | Definición |
|---|---|
| **Subtotal** | Suma de (precio unitario × cantidad) de todas las líneas del carrito, antes de descuento, envío e IGV. |
| **Descuento** | Monto restado del subtotal por aplicar un código válido de tipo porcentaje. |
| **Base imponible** | Subtotal menos descuento. Es la base sobre la que se calcula el IGV. |
| **IGV** | Impuesto General a las Ventas (Perú), 18%. Se calcula sobre la base imponible. |
| **Envío** | Costo de despacho. $8 plano, gratis sobre cierto umbral o con código. |
| **Total** | Lo que paga el cliente: base imponible + envío + IGV. |
| **Código de descuento** | Texto que el usuario ingresa en el carrito para obtener un beneficio (porcentaje o envío gratis). |
| **Producto agotado** | Producto con stock 0. No se puede agregar al carrito. |
| **Línea del carrito** | Un producto y su cantidad dentro del carrito. |
| **Credencial de demo** | Usuario/contraseña de prueba que permite iniciar sesión: `demo@nimbo.store` / `nimbo123`. |
